# 渠道规范 channels

做新媒体内容运营，先定渠道再排版。同一套选题按渠道各出一版，不要一张图打天下。

## 渠道一览

| 渠道 | 用途 | 尺寸（宽×高） | 说明 |
|---|---|---|---|
| `xiaohongshu` 小红书图文 | 封面＋内页 | 1080×1440（3:4） | 首图=封面；竖图流量最好；标题≤20字；正文配3–5个话题 |
| `wechat-cover` 公众号封面 | 封面图 | 900×383（约2.35:1） | 标题压图，注意左右各留60px安全区；小图模式会被裁成1:1，核心信息放中间 |
| `wechat-body` 公众号正文图 | 正文配图 | 900×1200（可按内容加长） | 手机端显示宽677px；字≥40px（按900宽折算）才看得清 |
| `poster` 私域海报 | 朋友圈/社群一图流 | 1080×1920（9:16） | 信息密度最高的一版：标题+3个卖点+行动指令+二维码位 |
| `poster-square` 私域方图 | 社群/对话框 | 1080×1080（1:1） | 缩略图也看得清标题，字要大 |
| `douyin` 抖音图文/视频 | 图文 1080×1920（9:16）＋视频成片 | 图文可直接发图文模式；视频走 `references/video.md`（TTS配音+跟读字幕+进度条→MP4） |

## 排版原则

1. **一套选题，多套版式**：不要对 1440×1920 的母版做简单缩放/裁切（3:4 裁掉左右会切字，2.35:1 压扁会糊字）。用 `scripts/layout.py` 的 `set_channel()` 切换画布，按渠道重排。
2. **坐标用相对值**：手排时 x/y/w 全部用 0–1 相对坐标，字号按"相对宽度"心算（同字号在 1080 宽画布上视觉更大），跨渠道复用同一套 `build()` 函数。
3. **封面单独排**：宽幅封面（`wechat-cover`）构图和竖版完全不同，单独写一版，不要复用竖版参数。
4. **安全区**：各渠道四边各留 ≥5% 不排关键信息（标题/大数字/二维码），小红书左右各留 8%。
5. **字号下限**（按各渠道宽度折算，不小于）：小红书正文 42px / 公众号正文 40px / 海报正文 44px；标题至少是正文的 1.8 倍。

## 出图清单

一次任务按用户选的渠道交付，每渠道一个文件夹：`交付/xiaohongshu/`、`交付/wechat/`……每个文件夹内含：该渠道全套 PNG（按 `01-封面.png`、`02.png`……命名）、`全套预览.jpg`、该渠道文案（见 copywriting.md）。
