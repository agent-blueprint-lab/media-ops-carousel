# 各渠道文案规范 copywriting

图和文案一起交付，文案按渠道各写一份，存在任务笔记目录，`package` 时分别打包。

## 完整素材包（每个渠道必须齐套，缺一项都不算交付）

运营同学拿到就能直接用，不再找你要东西。打包前逐项核对：

| 渠道 | 图片 | 文案 | 其他 |
|---|---|---|---|
| 小红书 | 封面+内页组图（`01-封面.png`…）、`全套预览.jpg` | `标题.txt`（3备选）、`正文.txt`、`话题.txt`、`置顶评论.txt` | `来源.md` |
| 公众号 | 封面图（900×383）、正文配图2–3张（900×1200） | `标题.txt`（3备选）、`摘要.txt`、`封面文案.txt`、`正文.txt`（可直接粘贴的文章） | `来源.md` |
| 私域 | 海报（1080×1920 或 1080×1080） | `文案.txt`（≤100字，含行动指令） | `来源.md`、二维码图（如有） |
| 抖音 | 图文组图（1080×1920）＋视频成片MP4 | `标题.txt`、`话题.txt`、`口播文案.txt` | `来源.md` |

`来源.md` 每个渠道包里都要有一份（同一选题可复用同一份）。

## 小红书（标题.txt / 正文.txt / 话题.txt）

- **标题**：≤20字，3个备选；钩子前置（数字/反差/提问），不说教。
- **正文**：开头50字讲清"这篇讲什么、跟我有什么关系"；分段+emoji+小标题，读完即走；结尾一句互动提问。
- **话题**：3–5个，1个大流量词+2个精准词+1个品牌词；不要堆10个。
- **置顶评论**：出处、口径说明、勘误通道（沿用 cy-carousel 的事实红线：每个数字回一手出处）。

## 公众号（标题.txt / 摘要.txt / 封面文案.txt）

- **标题**：≤30字，可比小红书更正式，保留钩子。
- **摘要**：≤120字，讲清价值，不剧透全文。
- **封面文案**：封面图上的字≤12字，单独成行，手机小图能看清。
- 正文图片按 `wechat-body` 尺寸出，图说一句话。

## 私域（文案.txt）

- 一段话≤100字：讲清是什么+为什么现在看+行动指令（扫码/回复关键词）。
- 海报上必须留二维码位（右下，≥200×200px），不要用文字代替。

## 抖音图文/视频（标题.txt / 话题.txt / 口播文案.txt）

- **标题**：≤20字，话题2–3个。
- **图文版**：每页按2–3秒阅读节奏排，单页字≤80。
- **视频版**：见 `references/video.md`。`口播文案.txt` 即 `narration.json` 的文字版（每页一段，标页码），运营可直接对照成片。

## 通用红线（所有渠道）

1. 事实可回溯：每个数字、引文、日期回一手出处，写进 `research/事实表.md`；单案例不写成普遍结论；没证据的说法不写。
2. 只用开放授权素材，记原链接、许可、SHA256、用页；图上不写出处，出处放文案与 `来源.md`。
3. 不改原文：引用条文/判决原样呈现，标注是后加的。
4. 不自动发布：只出文件，发布由用户自己来。
